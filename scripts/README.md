# 유틸리티 스크립트

프로젝트 관리를 위한 유틸리티 스크립트 모음입니다.

## clear-orders.mjs

테스트/개발 중 쌓인 대기 주문들을 일괄 완료 처리하는 스크립트입니다.

### 기능

- PENDING, COOKING, READY 상태의 모든 주문을 조회
- 각 주문을 COMPLETED 상태로 변경
- 처리 전 확인 메시지 표시
- 처리 결과 요약 표시

### 사용법

```bash
# 방법 1: npm 스크립트 사용
npm run clear-orders

# 방법 2: 직접 실행
node scripts/clear-orders.mjs
```

### 환경 변수

- `API_URL`: API 서버 주소 (기본값: `http://localhost:3001`)

커스텀 API URL 사용:
```bash
API_URL=http://localhost:4000 npm run clear-orders
```

### 주의사항

- 이 스크립트는 개발/테스트 환경에서만 사용하세요
- 실행 전 반드시 확인 메시지가 표시됩니다
- API 서버가 실행 중이어야 합니다
